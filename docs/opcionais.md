# Frentes opcionais — escopo da Parte 3

Não foram adicionados multiagente, MCP ou processamento multimídia, pois o case
continua atendido por um workflow de agente único, ferramentas Python e API Mistral.
Não usar essas frentes não foi tratado como deficiência nem compensado com componentes
sem necessidade. ASI07 não se aplica a comunicação entre agentes inexistentes.

O vídeo e os slides de apresentação são materiais produzidos fora da aplicação.
Eles não tornam o agente multimodal: a CLI aceita texto e retorna JSON.
Se no futuro o produto receber imagem/áudio, será preciso avaliar esse novo canal,
custo, formato, riscos e dataset antes de documentá-lo como implementado.
